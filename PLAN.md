# anystride — Project Plan

> Free, community-sourced running training plans for any distance and any runner.
> Domain: **anystride.com**

## Vision

A fast, free, no-login website where any runner can pick their **goal distance** and
**experience level** and get a complete, week-by-week training plan. Plans are
**curated from the running community** (the r/running, r/AdvancedRunning,
r/firstmarathon, r/C25K wikis and their endorsed methodologies) rather than
generated by AI. The value proposition is trust, clarity, and zero friction:
no sign-up, no paywall, no app install.

## Principles

- **Free forever** for the core plans. No login required to view or follow a plan.
- **Community-grounded.** Every plan cites its source/methodology and links out.
  We do not republish copyrighted plans verbatim — we encode well-known,
  freely-published methodologies (e.g. Couch-to-5K) and link to originals for the rest.
- **Fast & static.** Plans are local data, prerendered to static HTML. Cheap/free to
  host on Vercel, great SEO, instant loads.
- **Accessible.** Mobile-first, readable, printable plans.

## Tech stack

- **Next.js 16** (App Router, TypeScript, static export-friendly)
- **Tailwind CSS v4**
- **Vercel** hosting + `anystride.com` custom domain
- No database, no auth, no server APIs for v1 — all plan data ships in the bundle.

> Note: this repo pins Next.js 16.2.6, which has breaking changes vs. older docs.
> `params` is a `Promise` (must be awaited); route prop types use the generated
> `PageProps<'/route'>` helper. See `AGENTS.md`.

## Data model

```ts
type Distance = '5k' | '10k' | 'half-marathon' | 'marathon' | 'ultra'
type Level    = 'beginner' | 'intermediate' | 'advanced'
type WorkoutType =
  | 'rest' | 'walk-run' | 'easy' | 'long' | 'tempo'
  | 'interval' | 'cross' | 'race'

interface Workout { type: WorkoutType; label: string; note?: string }
interface PlanWeek { week: number; focus?: string; days: Workout[] /* 7, Mon–Sun */ }

interface TrainingPlan {
  slug: string
  name: string
  distance: Distance
  level: Level
  durationWeeks: number
  daysPerWeek: number
  summary: string
  source: { name: string; url: string }   // attribution / community link
  communityNote?: string                    // why the community recommends it
  weeks: PlanWeek[]
}
```

## Content roadmap

**Shipped in scaffold (real, full plans):**
- Couch-to-5K — beginner / 5k (9 weeks). Freely-published NHS/community methodology.
- Base Building 4-Week — beginner / 5k. Generic methodology-based.
- Bridge to 10K — intermediate / 10k. Methodology-based.

**To source & add (need attribution + linking, not verbatim copy):**
- Half marathon: Hal Higdon Novice 1/2, intermediate; community "first half" plans.
- Marathon: Hal Higdon, Pfitzinger 18/55, Hansons (beginner/advanced).
- Advanced: Jack Daniels (VDOT-based), 80/20 plans.
- Ultra: 50K intro plans.

Each added plan must: cite source, link to the original, and either use a
freely-publishable methodology or summarize + link (not reproduce paid content).

## Roadmap beyond v1

1. **VDOT/pace calculator** — enter a recent race time, get target paces per workout.
2. **Plan finder quiz** — a few questions → recommended plan.
3. **Printable / calendar export** (.ics, PDF).
4. **Plan comparison** table.
5. **Optional accounts** to save progress (only if there's demand — keep core free).
6. Possible later: pull the old `ai-running-coach` AI/Strava features back in as an
   optional premium layer, kept strictly separate from the free core.
7. **Coach marketplace** — the strategic bet: use the free plans as a trusted,
   high-intent funnel to connect runners with vetted human coaches, solving the
   "how do I know if a coach is any good?" problem. Full analysis in
   [`COACH-MARKETPLACE.md`](./COACH-MARKETPLACE.md). Free plans → directory →
   marketplace, phased.
